R&G — музыкальный плеер
R&G — настольное приложение для Windows, предназначенное для управления локальной музыкальной коллекцией и воспроизведения аудиофайлов.

Возможности

 ● добавление аудиофайлов форматов MP3 и WAV в медиатеку;
 ● автоматическое формирование названия и исполнителя по имени файла в формате Исполнитель - Название;
 ● поиск композиций по названию или исполнителю;
 ● создание и удаление плейлистов;
 ● добавление композиций в плейлисты и исключение их из плейлистов;
 ● воспроизведение, пауза, остановка, переход к предыдущей и следующей композиции;
 ● регулировка громкости и перемотка;
 ● повтор текущей композиции и случайный порядок воспроизведения;
 ● сохранение сведений о медиатеке и плейлистах в локальной базе SQLite.

Технологии

 ● C#;
 ● .NET 8;
 ● Windows Forms;
 ● SQLite;
 ● NAudio.

Требования

 ● Windows;
 ● .NET 8 SDK (для запуска из исходного кода);
 ● Visual Studio с поддержкой разработки классических приложений .NET для Windows.

Запуск из исходного кода

 1. Склонируйте репозиторий или скачайте его архив.
 2. Откройте RAndG.slnx в Visual Studio.
 3. Убедитесь, что установлены .NET 8 SDK и компонент Windows Forms.
 4. Соберите решение и запустите проект RAndG.

При первом запуске приложение автоматически создаёт локальную базу данных music_player.db.

Быстрый старт

 1. Нажмите «Добавить файл» и выберите MP3- или WAV-файл.
 2. Выберите композицию в медиатеке и нажмите ▶️.
 3. Для поиска введите название или исполнителя и нажмите «Поиск»; кнопка «Сбросить» возвращает полный список.
 4. Чтобы создать подборку, введите название плейлиста и нажмите «Создать».
 5. Для добавления песни выберите её в медиатеке, выберите плейлист и нажмите «Добавить в плейлист».

Важные замечания

 ● Приложение сохраняет путь к музыкальному файлу, а не копирует сам файл в папку приложения. После добавления не перемещайте и не переименовывайте аудиофайл.
 ● Удаление композиции из медиатеки приложения не удаляет исходный аудиофайл с компьютера.
 ● Сведения о медиатеке и плейлистах хранятся в music_player.db. Для переноса данных сохраните этот файл и сами аудиофайлы.
 ● Воспроизведение запускается выбором композиции из общей медиатеки. Переключение «следующая/предыдущая» выполняется в текущем отображаемом списке медиатеки.

Структура решения

 ● RAndG/ — основное Windows Forms приложение;
 ● RAndG/Data/ — работа с базой данных;
 ● RAndG/Models/ — модели композиций и плейлистов;
 ● RAndG/Services/ — логика медиатеки, плейлистов, проверки файлов и измерения производительности;
 ● RAndG.Player/ — отдельный проект с логикой воспроизведения.
