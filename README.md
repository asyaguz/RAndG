# 2. Назначение и цели создания системы

## 2.1. НАЗНАЧЕНИЕ СИСТЕМЫ

Программное обеспечение R&G предназначено для автоматизации работы пользователя с локальной музыкальной коллекцией, хранящейся на компьютере.

Система обеспечивает добавление и организацию аудиофайлов, поиск музыкальных композиций, создание и использование плейлистов, а также воспроизведение музыкальных файлов.

Автоматизируемыми объектами являются:

1.  локальные аудиофайлы;

2.  музыкальная библиотека;

3.  информация о музыкальных композициях;

4.  плейлисты;

5.  очередь воспроизведения;

6.  история воспроизведения;

7.  настройки воспроизведения.

Система не предусматривает потоковое воспроизведение музыки через сеть и предназначена для работы с локальными аудиофайлами.

## 2.2. ЦЕЛИ СОЗДАНИЯ СИСТЕМЫ

Основной целью создания R&G является разработка удобного локального музыкального проигрывателя, позволяющего хранить, просматривать, искать и воспроизводить музыкальную коллекцию в одном приложении.

Для достижения поставленной цели система должна обеспечивать:

1.  добавление локальных аудиофайлов;

2.  отображение информации о музыкальных композициях;

3.  поиск музыкальных файлов по доступной информации;

4.  сортировку и фильтрацию музыкальной коллекции;

5.  создание и редактирование плейлистов;

6.  воспроизведение выбранных музыкальных файлов;

7.  управление воспроизведением;

8.  регулировку громкости;

9.  перемещение по временной шкале воспроизведения;

10. использование режимов повтора и случайного воспроизведения;

11. сохранение пользовательских данных между запусками программы;

12. предоставление понятного графического интерфейса.

Результатом создания системы должна стать работоспособная версия R&G, реализующая указанные функции и не содержащая критических ошибок, препятствующих запуску программы и основному воспроизведению музыкальных файлов.

# 3. Характеристика объектов автоматизации

## 3.1. ОБЩАЯ ХАРАКТЕРИСТИКА ОБЪЕКТА АВТОМАТИЗАЦИИ

Объектом автоматизации является работа пользователя с локальной музыкальной коллекцией на персональном компьютере.

Музыкальная коллекция пользователя может находиться в различных каталогах и на различных доступных накопителях компьютера. При использовании стандартных средств операционной системы организация музыкальных файлов, их поиск и воспроизведение осуществляются раздельно.

Программное обеспечение R&G предназначено для объединения основных операций с музыкальной коллекцией в рамках одного приложения и обеспечения централизованного доступа к аудиофайлам, поиску, плейлистам и средствам воспроизведения.

## 3.2. УСЛОВИЯ ЭКСПЛУАТАЦИИ

Программное обеспечение предназначено для эксплуатации на персональном компьютере под управлением операционной системы Windows.

Для работы системы необходимы:

- персональный компьютер;
- операционная система Windows;

- свободное место на диске;
- локальные аудиофайлы или аудиофайлы на доступном компьютеру накопителе;

- устройство для вывода звука.

Для выполнения основных функций программы подключение к сети Интернет не требуется.

Эксплуатация программного обеспечения осуществляется в стандартных условиях использования персонального компьютера. Специальные требования к температуре, влажности, вибрации и радиационному воздействию не предъявляются.

## 1. Назначение программы и системные требования

R&G — настольный музыкальный плеер для Windows. Программа позволяет добавлять и искать музыкальные композиции, создавать плейлисты и управлять воспроизведением. Для работы требуется компьютер под управлением Windows. Для запуска из исходного кода необходимы Visual Studio с поддержкой Windows Forms и .NET 8 SDK. Поддерживаются аудиофайлы MP3 и WAV.

## 2. Порядок запуска программы

Запустите готовое приложение R&G. Для запуска из исходного кода откройте решение RAndG.slnx в Visual Studio и запустите проект RAndG. При первом запуске автоматически создаётся локальная база данных music_player.db.

## 3. Добавление музыкальных файлов и поиск

Нажмите «Добавить файл», выберите MP3- или WAV-файл и подтвердите выбор. Композиция появится в медиатеке. Если имя файла имеет формат «Исполнитель - Название», программа использует его части для заполнения данных о треке. Для поиска введите название композиции или исполнителя и нажмите «Поиск». Кнопка «Сбросить» возвращает полный список.

## 4. Плейлисты и управление воспроизведением

Для создания плейлиста введите его название и нажмите «Создать». Чтобы добавить композицию, выберите её в медиатеке, выберите плейлист и нажмите «Добавить в плейлист». Для удаления песни только из подборки выберите её в списке треков плейлиста и нажмите «Исключить трек». Для запуска выберите композицию и нажмите ▶. Кнопки проигрывателя: ⏮ — предыдущий трек, ▶ — воспроизведение, ⏸ — пауза, ⏹ — остановка, ⏭ — следующий трек. Ползунки регулируют позицию и громкость; флажки включают повтор трека и случайный порядок.

## 5. Описание пользовательского интерфейса

Главное окно содержит медиатеку со всеми композициями, список созданных плейлистов и список треков выбранного плейлиста. В нижней части расположены элементы управления проигрыванием: кнопки переключения треков, воспроизведения, паузы и остановки, индикатор времени, ползунок перемотки и регулятор громкости.

## 6. Действия при возникновении ошибок

Если файл не добавляется, проверьте его формат: поддерживаются MP3 и WAV. Если композиция не воспроизводится, убедитесь, что аудиофайл не был перемещён, переименован или удалён. Если песня не добавляется в плейлист, проверьте, что выбраны и композиция, и плейлист. Если данные медиатеки не отображаются, проверьте наличие файла music_player.db. При необходимости добавьте аудиофайл повторно.

**Важно:** программа хранит путь к аудиофайлу, а не копирует сам файл. Удаление композиции из медиатеки не удаляет исходный файл с компьютера. Для сохранения медиатеки и плейлистов сделайте резервную копию music_player.db.
